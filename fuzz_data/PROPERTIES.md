# BOBC protocol stateful properties

Units: BOBC and crvUSD amounts use 18-decimal wei; rates and collateral ratios use 1e18 scaling; cashback uses basis points over 10,000; time is seconds. All contract conversions use integer floor rounding unless the contract explicitly rounds up a minimum collateral requirement.

## Global properties

- [x] **GL-01** — Supply accounting (`Accounting`, `src/vault_engine.vy:total_debt`, `bad_debt`; `src/bobc.vy:totalSupply`). After every successful or deliberately rejected action, `BOBC.totalSupply == engine.total_debt + engine.bad_debt`. Debt includes accrued fee debt; uncovered debt remains represented by `bad_debt`. Assertion: `Properties.global_supply_matches_debt_and_bad_debt`; hook: Hypothesis invariant. Implemented and executed in the standard run. Guarantee: SHOULD-HOLD.
- [x] **GL-02** — Engine fee inventory (`Accounting`, `src/vault_engine.vy:surplus`, `_accrue`, `_burn_fee`). The engine's BOBC balance equals `surplus`, which tracks interest minted to the engine and not yet burned. Assertion: `Properties.global_engine_bobc_is_fee_surplus`; hook: Hypothesis invariant. Implemented and executed in the standard run. Guarantee: SHOULD-HOLD.
- [x] **GL-03** — Position and list books (`Structure`, `src/vault_engine.vy:total_debt`, `total_shares`, `position`; `src/sorted_positions.vy`). The acyclic ascending-rate list contains exactly modeled open borrowers; sum of listed debt and shares equals the public totals; each listed position has positive principal and each unlisted modeled borrower has a zero position. Assertion: `Properties.global_position_books_and_ordered_acyclic_list`; hook: Hypothesis invariant. Equal rates may appear in either adjacent order while remaining nondecreasing. Implemented and executed in the 100-example standard run. Guarantee: SHOULD-HOLD.
- [x] **GL-04** — Insurance asset custody (`Accounting`, `src/vault_engine.vy:insurance_assets`, `liquidate`). Engine-held idle crvUSD equals recorded insurance assets after each completed operation. Assertion: `Properties.global_idle_crvusd_is_accounted_as_insurance`; hook: Hypothesis invariant. This assumes no external donation directly to the engine; the state machine does not make such donations. Implemented and executed in the standard run. Guarantee: SHOULD-HOLD.
- [x] **GL-05** — Merchant set synchronization (`Access`, `src/cashback.vy:MERCHANTS`, `is_merchant`, `set_merchants`, `add_merchant`, `remove_merchant`, `clear_merchants`). The merchant array is unique and equals the Python set updated only after successful owner calls; every modeled merchant map value matches membership. Assertion: `Properties.global_cashback_list_matches_membership_map`; hook: Hypothesis invariant. Implemented and executed in the standard run. Guarantee: SHOULD-HOLD.
- [x] **GL-06** — Cashback owner handoff (`Access`, `src/cashback.vy` Snekmate `ownable_2step` exports). Chain `owner()` and `pending_owner()` equal the independent model after a transfer and acceptance. Assertion: `Properties.global_cashback_ownership_model_matches_chain`; hook: Hypothesis invariant. Implemented and executed in the standard run. Guarantee: SHOULD-HOLD.

## Action properties

- [x] **SP-01** — Position opening (`Accounting`, `src/vault_engine.vy:open_position`). A successful open creates an existing position with the requested debt and positive shares, mints the requested debt to the borrower, and preserves the tracked supply/debt invariant. Share-to-asset conversion can floor below the deposit amount by one or more asset wei; no exact asset equality is assumed. Assertion: `Properties.check_opened_position`; hook: `Actions.open_position`. Guarantee: SHOULD-HOLD.
- [x] **SP-02** — Collateral addition (`Accounting`, `src/vault_engine.vy:add_collateral`, `_pull_deposit`). A successful positive addition increases position shares and reduces borrower crvUSD by the deposited amount. Assertion: `Properties.check_position_collateral_increased`; hook: `Actions.add_collateral`. Guarantee: SHOULD-HOLD.
- [x] **SP-03** — Collateral withdrawal threshold (`Solvency`, `src/vault_engine.vy:withdraw_collateral`). A successful withdrawal leaves the position at or above `MIN_CR` using the current oracle value and pending interest. Assertion: `Properties.check_withdraw_keeps_minimum_ratio`; hook: `Actions.withdraw_collateral`. Guarantee: SHOULD-HOLD.
- [x] **SP-04** — Additional borrowing (`Accounting`, `src/vault_engine.vy:borrow`, `_accrue`). Borrowing adds requested BOBC to the borrower and requested amount plus pre-call accrued interest to recorded debt. Assertion: `Properties.check_borrow_minted`; hook: `Actions.borrow_more`. Guarantee: SHOULD-HOLD.
- [x] **SP-05** — Principal repayment (`Accounting`, `src/vault_engine.vy:repay`, `_accrue`). Repayment burns only the requested principal from the caller and accrues pending interest to position debt and fees before applying the repayment. Assertion: `Properties.check_repayment`; hook: `Actions.repay`. Guarantee: SHOULD-HOLD.
- [x] **SP-06** — Position closure (`Accounting`, `src/vault_engine.vy:close_position`, `_clear_position`, `_redeem_all`). Closing clears borrower debt, fees, and shares from the position and returns the represented collateral to the borrower. Assertion: `Properties.check_position_closed`; hook: `Actions.close_position`. Guarantee: SHOULD-HOLD.
- [x] **SP-07** — Rate change (`Structure`, `src/vault_engine.vy:set_rate`, `src/sorted_positions.vy:_remove`, `_insert`). A successful rate update stores the requested rate; GL-03 checks the reinserted list order. Assertion: `Properties.check_rate_changed`; hook: `Actions.set_rate`. Guarantee: SHOULD-HOLD.
- [x] **SP-08** — BOBC transfer conservation (`Accounting`, `src/bobc.vy` ERC-20 exports). A transfer debits and credits the requested amount and leaves total supply unchanged. Assertion: `Properties.check_transfer`; hook: `Actions.transfer_bobc`. Guarantee: SHOULD-HOLD.
- [x] **SP-09** — Cashback inventory funding (`Accounting`, `src/cashback.vy:pay`, `src/bobc.vy` ERC-20 exports). Funding transfers preminted BOBC without changing total supply. Assertion: `Properties.check_supply_unchanged`; hook: `Actions.fund_cashback`. Guarantee: SHOULD-HOLD.
- [x] **SP-10** — Cashback payment and rebate (`Accounting`, `src/cashback.vy:pay`). A successful payment transfers `amount` to the merchant, debits `floor(amount * BPS / 10,000)` from finite inventory, credits that rebate to the payer, and preserves supply. Assertion: `Properties.check_cashback_payment`; hook: `Actions.pay_cashback`. Guarantee: SHOULD-HOLD.
- [x] **SP-11** — Unauthorized mint rejection (`Access`, `src/bobc.vy:mint`). A non-engine caller cannot mint; supply and recipient balance remain unchanged. Hook: `Actions.unauthorized_mint`; narrow `BoaError` plus reason and snapshot check. Guarantee: SHOULD-HOLD.
- [x] **SP-12** — Stale-oracle addition rejection (`Oracle`, `src/vault_engine.vy:add_collateral`). The current policy requires a fresh oracle for addition; when stale, the call reverts without changing position, borrower balance, or shares. Hook: `Actions.stale_oracle_blocks_add_collateral`; narrow `BoaError` plus reason and snapshot check. Guarantee: SHOULD-HOLD.
- [x] **SP-13** — Invalid list hint rejection (`Structure`, `src/vault_engine.vy:open_position`, `src/sorted_positions.vy:_assert_hints`). A nonadjacent unlinked hint rejects an attempted open without changing debt or supply. Hook: `Actions.invalid_list_hints_revert`; narrow `BoaError` plus reason and snapshot check. Guarantee: SHOULD-HOLD.
- [x] **SP-14** — Cashback BPS bounds (`Access`, `src/cashback.vy:set_cashback_bps`). A value above 200 basis points rejects without changing the configured rate. Hook: `Actions.invalid_cashback_limit_reverts`; narrow `BoaError` plus reason and snapshot check. Guarantee: SHOULD-HOLD.
- [x] **SP-15** — Cashback owner gate (`Access`, `src/cashback.vy:set_cashback_bps`). An address other than the modeled owner cannot change the rate. Hook: `Actions.unauthorized_cashback_admin_reverts`; narrow `BoaError` plus reason and snapshot check. Guarantee: SHOULD-HOLD.
- [x] **SP-16** — Empty rebate inventory atomicity (`Accounting`, `src/cashback.vy:pay`). A positive rebate cannot be paid from an empty pool; payer, merchant, pool, and allowance remain unchanged. Hook: `Actions.empty_cashback_pool_reverts_atomically`; narrow `BoaError` plus reason and snapshot check. Guarantee: SHOULD-HOLD.

## Exploratory and pending properties

- [ ] **GL-07** — Full token balance sum (`Accounting`, `src/bobc.vy` ERC-20). Enumerate every possible holder and prove that their balances sum to total supply. This is exploratory because a general external caller may hold BOBC at any address; the state machine tracks only its modeled actor and protocol addresses. Guarantee: EXPLORATORY.
- [ ] **GL-08** — ERC-4626 redeemability (`Integration`, `src/vault_engine.vy`, configured real vault). Position share totals are checked against the engine's own books, but real-vault loss, withdrawal limits, asynchronous exits, and fee-on-transfer behavior are outside the local mock. The Arbitrum fork test remains required for the configured vault and is conditional on `ARBITRUM_RPC`. Guarantee: EXPLORATORY.
- [x] **SP-17** — Redemption conservation and floor (`Accounting`, `src/vault_engine.vy:redeem`, `_redeem_from`, `_bounded_redemption`). Check that the reduction in aggregate position principal equals the external BOBC burned, every surviving debt respects the floor, assigned shares fall, and direct crvUSD output reaches the redeemer. A borrower who redeems their own final principal also receives residual shares, so their total asset increase may exceed the return value. Assertion: `Properties.check_redemption`; hook: `Actions.redeem`. Executed with 30 successful redemptions in the latest standard run. Guarantee: SHOULD-HOLD.
- [x] **SP-18** — Liquidation payout (`Solvency`, `src/vault_engine.vy:liquidate`, `_payout`). Independently calculate both payout branches from position value, accrued fee debt, oracle rate, and insurance. Check liquidator BOBC burn and asset payout, borrower remainder, insurance delta, fee surplus, position shares/debt removal, bad-debt delta, and supply. Assertion: `Properties.check_liquidation`; hook: `Actions.liquidate`. Executed with 51 successful liquidations in the latest standard run. Guarantee: SHOULD-HOLD.
- [x] **SP-19** — Insufficient collateral balance reverts atomically (`Accounting`, `src/vault_engine.vy:add_collateral`). A borrower cannot add one wei more crvUSD than their wallet holds; the position, wallet, vault, debt, shares, fee surplus, and BOBC supply remain unchanged. Assertion: snapshot comparison in `Actions._assert_unchanged_after_revert`; hook: `Actions.inadequate_collateral_balance_reverts`. Executed with 388 expected reverts in the latest standard run. Guarantee: SHOULD-HOLD.
- [x] **SP-20** — Final-principal repayment cannot leave fee-only nodes (`Structure`, `src/vault_engine.vy:repay`, `position`, `next`). When accrued fees reach the debt floor, repaying all remaining principal reverts without changing debt, fee surplus, BOBC supply, or borrower balance; the borrower must use `close_position` to unlink and return collateral. Assertion: `Actions.final_principal_repayment_reverts` plus GL-03's positive-principal condition; hook: `Actions.final_principal_repayment_reverts`. Executed with 72 expected reverts in the latest standard run. Guarantee: SHOULD-HOLD.
